## Key Design Decisions
1. **`include = ["src*"]` not `where = ["src"]`** — preserves existing `from src.finance.xyz` import pattern throughout codebase
2. **`[dependency-groups] dev`** — enables `uv sync --group dev` (uv's native mechanism), in addition to `[project.optional-dependencies] dev` for pip compatibility
3. **No `initializeCommand`** — volumes use Docker Compose auto-prefixing (project name prefix) for isolation, no need for `docker volume create`
4. **No `external: true` on volumes** — simpler, auto-managed by compose
5. **Python 3.12 via `uv python install`** — Debian bookworm only ships 3.11 in apt, so uv manages the 3.12 build

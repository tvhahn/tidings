## Direction options (for the maintainer to weigh, not ranked against bugs)

- **Ship the `finance-mcp` stdio server.** `ROADMAP.md:21` lists it.
  `scripts/agent/agent-bootstrap.py:84-114` already detects `src/mcp_server/`
  and prints a Claude Desktop config for it. Bearer scopes and the activity
  ledger with revert already give agents authentication and undo. A thin
  server over 10–15 curated `operationId`s is a medium spike. The trade-off
  is another public surface to keep in sync with `openapi.json`.
- **Bank CSV import into the statement pipeline.** Export exists
  (`exportTransactionsCsv`), but upload accepts only PDFs
  (`src/api/routers/statements.py:83`). `StatementParseResult` doesn't
  depend on the file format, so CSV could reuse reconcile → review → import.
  That would let users backfill history from before their alerts began. The
  trade-off is per-bank column mapping, and it sits in mild tension with the
  "email-first" identity.
- **A statement-parser version of `add-a-parser`.** `ROADMAP.md:17` asks for
  statement coverage beyond RBC and Simplii. `statement_parser_ai.py` already
  produces validated results for other banks, so each AI-parsed statement
  could seed a deterministic parser. The main new work is a scrubbing step
  for PDF text.

## Findings considered and rejected

- **Route code-splitting / table virtualization (desktop)**: already done
  (`frontend/src/App.tsx:21-73` lazy routes, `TransactionTable.tsx:481` virtualizer).
- **Splitting `frontend/src/lib/queryConfigs.ts` (1145 lines)**: it is a
  deliberate, ESLint-enforced registry, so splitting it adds churn without benefit.
- **DynamoDB month reads as Scans**: they are `Query` + `begins_with` (`src/finance/spending_summary.py:53`).
- **SQL injection in SQLite modules / search**: every dynamic statement uses fixed fragments plus bound parameters, and search filters in Python.
- **Bearer scope bypass through path or method normalisation**: none found. HEAD is denied for the `read` scope, and OPTIONS is handled by CORS or returns 405.
- **Committed secrets**: none. The only token-shaped strings are placeholder examples in `docs/guides/agent-access.md`.
- **`pip-audit` advisories** (anyio, soupsieve, tornado and others): none are high or critical in reachable runtime code. They are routine upgrades, not findings.
- **Floats for money, sync services via `run_sync`, auth open until a password is set**: these are documented design decisions, not findings.
- **`twilio` as a required dependency**: it is imported lazily, so making it optional saves little.
